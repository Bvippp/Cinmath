Full Films Explained

How full playback works

Server 1 • Archive.org FULL: Public-domain classics (1920s-1960s) play full legal via archive.org/embed — same as Internet Archive.

Server 2 • Trailer HD: Official YouTube trailers for all modern movies.

Server 3 • Full Embed (like Movy.sx): Uses third-party aggregator embed (VidSrc-style: vidsrc.to / vidsrc.in / vidcore). Movy.sx uses same pattern — scraping third-party sources client-side. Enable by adding TMDB ID to FULL_EMBED list. We include working examples for testing. All Hollywood full playback depends on third-party availability.

For a published site, keep Server 1 + 2 as legal default. Server 3 requires user responsibility similar to Movy.sx DMCA note.
